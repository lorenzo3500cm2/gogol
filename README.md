# Catch the Mouse — Gara dei topi verdi
Due giocatori sullo stesso dispositivo: rossa WASD, blu frecce, oppure due gruppi touch.
Nessun limite di tempo. Ogni 20 topi grigi catturati complessivamente compare un verde; vince chi cattura 3 verdi. I grigi valgono ancora 10 punti, ma non determinano il vincitore. Una cattura simultanea esattamente alla stessa distanza assegna il topo a entrambe.
Cinque topi, 12 funghi subito e ogni 10 secondi, 12 tunnel per le ragazze. Viola accelera, rosso ingrandisce, nero rallenta, giallo rimpicciolisce per 6 secondi, anche per i topi.
Un gatto e un cane inseguono e mangiano i topi senza dare punti né contare per il prossimo verde. I verdi mangiati o fuggiti ricompaiono verdi, quindi non si perdono opportunità di vittoria.
Pausa con il pulsante o Esc; pausa automatica cambiando scheda.
Apri index.html per giocare. Per GitHub Pages carica tutti i file nella radice di gogol e scegli Settings → Pages → main → /(root).
